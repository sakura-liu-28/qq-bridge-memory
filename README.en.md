# QQ Bridge Memory

A QQ AI companion with persistent memory.

## Features

- Private and group conversations with participation, idle and wake behavior.
- Custom personas with role and conversation scoped context.
- Two persistent memory modes, with search, browsing and editing.
- Speech synthesis, speech recognition, vision and image generation.
- Multiple API connections with custom URLs, keys, models and optional names.
- A responsive console for roles, conversations, memory, access and usage.
- Conversation isolation, allowlists and configurable tool permissions.

## Upstream and prerequisites

Derived from [Derpyu520/qq-bridge](https://github.com/Derpyu520/qq-bridge), retaining the original attribution and MIT license.

Requires [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), the conversation runtime, and [SnowLuma](https://github.com/SnowLuma/SnowLuma), the QQ OneBot gateway. Chat APIs use the integrations supported by DSH; downloading a DeepSeek model is not required.
