# 可视化能力配置

控制台左侧「声音与图片」显示四项能力及当前使用的服务。点击卡片上的「设置」更换服务；点击「添加服务」连接新的 API。备用服务、音色和权限等参数收在弹窗的更多设置中：

| 能力 | 可选择的已接入服务 | 配置项 |
| --- | --- | --- |
| 语音合成 | 火山引擎、Edge TTS | 音色、已有复刻音色、自定义已授权音色、密钥；Edge 的 Python 路径 |
| 语音识别 | 火山流式 ASR 2.0 | 开关、允许识别的私聊 QQ、单条最长时间、密钥 |
| 图片识别 | 智谱、硅基流动、已配置的火山/百炼模型 | 模型、自动识图、密钥、百炼业务空间 |
| 图片生成 | 智谱、硅基流动、火山、百炼 | 模型、密钥、参考图使用方式、百炼业务空间 |

## 添加多个服务

点击「添加服务」，选择用途，填写 API 地址、Key 和模型。服务商不必选择，备注名称选填；不填则显示域名。「更多设置」中的接口格式默认自动识别，也可手动更换。百炼需要填写自己的业务空间完整请求地址。允许同平台多组配置，也允许兼容同一协议的自定义公网地址；识图支持标准 Chat Completions，生图支持标准 Images Generations；兼容格式下可填写自定义模型 ID。基础地址如 `https://example.com/v1` 会补全请求路径。原有专用接口及额度保护保留；语音仍使用火山 TTS/流式 ASR 格式，不能只换地址就接入另一种协议。

点击「保存并使用」一次完成保存与启用；「仅保存」留作候选，之后在能力卡片设置中选择并保存。编辑 Key 留空保留原值；可编辑名称、地址、模型和接口格式，并保留独立凭据。正在使用或在启用备用队列中的服务需先换下才能删除。普通语音和 QQ 电话的声音仍分别配置。

## 备用与额度

识图、生图可增加备用服务、上移顺序或移除，保存后生效。只有明确免费额度耗尽才尝试下一项；网络、鉴权、限流与内容拒绝直接报错，不重复创建生成任务。同平台同模型的不同连接使用各自的额度状态，旧连接和原有队列的额度记录不清空。切换普通模型时保留原有请求次数保护。

火山和百炼的受保护额度配置须先在供应商平台开启免费额度用完即停，并在添加或配置时确认。ASR 保留已有累计时长保护与指定私聊白名单；聊天白名单不会自动扩大 QQ 电话名单。

## 保存与验证

Key 不回显，新 Key 存入 `state/secrets/`；配置文件只保存私有文件路径。保存不会调用模型或发 QQ 消息，「已保存」不表示服务已开通或有额度。首次启用或工具开关变化后，按页面提示重启 DSH/MCP。

角色参考图在页面下方预览和上传，支持 PNG/JPEG/WebP、最大 8 MB；固定参考图需要支持参考图的火山模型。

`npm run test:capabilities` 使用临时配置验证管理 API、独立连接和备用路由；`npm run test:capabilities:ui` 验证浏览器中的添加、选择、保存与记忆模式。浏览器回归需 Playwright 与 Chromium，或通过 `PLAYWRIGHT_MODULE` 指向已有包。
