# QQ Bridge Memory

有长期记忆的 QQ AI 伙伴。

## 功能

- **QQ 对话**：支持好友私聊和群聊，可按情境参与、潜水和唤醒。
- **自定义角色**：编辑人格和表达风格，按角色、会话读取上下文。
- **长期记忆**：直接记录与智能整理两种模式，支持查看、搜索和编辑记忆。
- **语音与图片**：语音合成、语音识别、图片识别与图片生成。
- **多组 API 服务**：自定义地址、Key、模型与备注名称，支持主用和备用选择。
- **可视化控制台**：管理角色、会话、记忆、权限及用量，支持深浅主题和手机浏览。
- **访问控制**：聊天白名单、工具权限与按会话隔离的私有配置。
